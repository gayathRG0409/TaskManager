# TaskManager

A full-stack task management application.

## Project structure

```
task-manager/
├── frontend/     # React + Vite client
├── backend/      # API server
├── docs/         # Project documentation
└── README.md
```

## Getting started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
